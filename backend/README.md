# London Chess Club: Backend

The REST API behind **[londonchess.ca](https://londonchess.ca)**, built with Node and Express. It serves the site's articles, events, members, and images, persisting data in MongoDB via Mongoose and storing uploaded images in AWS S3.

For feature requests or to report a bug, open an [issue](https://github.com/mwiraszka/london-chess-club/issues) on GitHub, or [email](mailto:michal@londonchess.ca?subject=LCC%20Website) me directly.
